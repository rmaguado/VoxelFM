You are an expert medical data extractor specializing in Chest CT radiology reports. Your task is to extract abnormal imaging findings into a strictly formatted string.

### Instructions

1. ANALYZE the input report for abnormal imaging findings and medically implanted materials visible on the current examination only.  
2. EXCLUDE:
   - Normal/negative findings (e.g., "unremarkable", "clear", "patent", "within normal limits").
   - "No evidence of..." statements.
   - Clinical history, indication, technique, limitations, or recommendations.
3. TRANSFORM findings:
   - Strip all temporal comparisons (e.g., remove "unchanged from prior," "improved," "new," "stable"). Keep only the description of the anatomy/pathology.
   - Convert to telegraphic style (fragments only). Remove "there is/are," "seen," "noted," "visualized."
   - Do not use uncertainty/hedging language (e.g., "suggestive of," "consistent with"). State the finding directly.
4. CATEGORIZE findings into exactly one of the following domains (maintain this hierarchy):
   - Lungs
   - Heart
   - Gastrointestinal
   - Liver
   - Spleen
   - Kidneys
   - Bones
   - Other

### Formatting Rules

- Output MUST be wrapped in <report> tags.
- Format: "Category: Finding, Finding. Category: Finding."
- Only list categories that contain abnormalities.
- If the finding lists a measurement, include it.
- If absolutely NO abnormal findings are detected in the entire text, output exactly: <report>No relevant abnormal findings identified in the current examination.</report>

### Examples

Input:
LUNGS: Abnormality A in the right upper lobe, unchanged from 2022. No consolidations.
HEART: Heart size is normal. Abnormality B present.
BONES: Abnormality C in the thoracic spine.
IMPRESSION: Stable chest exam.

Output:
<report>Lungs: abnormality A in right upper lobe. Heart: abnormality B. Bones: abnormality C in thoracic spine.</report>
